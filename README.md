# CC_wep
## indroducion:
El proyecto Centro Comercial Web consiste en la creación de una página web sencilla que permite mostrar información sobre un centro comercial, sus tiendas, promociones y servicios disponibles para los visitantes.

La página fue desarrollada utilizando HTML, CSS y JavaScript. Su objetivo principal es ofrecer a los usuarios un sitio donde puedan conocer algunos de los establecimientos que tiene el centro comercial, consultar sus servicios y comunicarse mediante un formulario de contacto.

Este proyecto fue realizado como una actividad académica por estudiantes de grado 11, con el propósito de poner en práctica los conocimientos adquiridos durante las clases de desarrollo web.

## Descripción del proyecto
El sitio web representa un centro comercial en el que los visitantes pueden encontrar diferentes opciones de entretenimiento, compras y alimentación.

La página cuenta con un menú de navegación que permite desplazarse fácilmente entre sus diferentes secciones. También tiene imágenes representativas de las tiendas, información sobre promociones y una sección donde se presentan algunos de los servicios que ofrece el establecimiento.

Además, se agregó un formulario de contacto para que los visitantes puedan escribir su nombre, correo electrónico y un mensaje.

El diseño busca ser sencillo, organizado y fácil de utilizar, permitiendo que cualquier persona pueda navegar por la página sin tener dificultades.
